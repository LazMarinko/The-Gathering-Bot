# The Gathering Bot

A custom Python Discord bot built for Magic: The Gathering communities, featuring deckbuilding tools, card utilities, and server automation.

## Features

* Automatically posts newly revealed MTG cards
* Checks card rulings and card information
* Helps trim Commander decklists to 100 cards
* Utility commands for MTG players
* Discord server automation features

## Purpose

The Gathering Bot is designed to help Magic: The Gathering players manage decks, check rulings, and stay updated with newly revealed cards directly inside Discord.
